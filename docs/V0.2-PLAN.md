# Forge v0.2 — Supabase foundation

This branch replaces the v0.1 local-only persistence layer with a secure Supabase-backed data layer while preserving a demo fallback when Supabase environment variables are not configured.

## Scope

- Supabase client integration using publishable browser credentials only
- Auth gate for cloud mode
- Projects and tickets persisted in Postgres
- Acceptance criteria persisted separately
- Ticket comments
- Agent run history and pipeline projection
- Ticket activity audit trail
- RLS on every exposed table
- GitHub Pages-compatible Vite environment variables
- Demo mode remains available without secrets

## Deliberate non-goals

- Multi-user project sharing
- Agent orchestration runtime
- Webhooks / GitHub sync
- Attachments
- Notifications

Those belong to later milestones.
