# Forge agent team

These role files define the repository-local operating contract for the six Forge execution agents. Forge ticket state is work truth; GitHub is code truth.

Roles: Planner -> Builder -> Reviewer -> QA -> Runtime -> Release.

All agents must read `AGENTS.md`, `.forge/project.json`, `.forge/agent-api.md`, and the active Forge ticket before acting. Product ambiguity must become a Decision Request instead of an invented requirement.

Sunday 2026-09-13 is the first operating day for this team. Work may be queued/claimed on weekends; release gates remain evidence-based.
